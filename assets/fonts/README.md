# Share-card font

JetBrains Mono Regular 2.304 is vendored from the
[official release](https://github.com/JetBrains/JetBrainsMono/tree/v2.304),
under the adjacent SIL Open Font License. It is embedded only in the build-time
Open Graph card. Page fonts continue to use the existing `next/font` setup.

The `ec` favicon glyphs also derive from this font. Neither asset adds a runtime
font request.
